# El Pollo Loco

Ein Jump'n'Run Browser-Game im Stil von Super Mario, entwickelt mit HTML, CSS und JavaScript.

## Projektstruktur

- **index.html** – Hauptseite des Spiels
- **style.css** – Globale Styles (Layout, Buttons, Grundfarben)
- **impressum.css** – Styles für das Impressum
- **endscreen.css** – Styles für den Endscreen
- **startscreen.css** – Styles für den Startscreen
- **controls.css** – Styles für die Steuerung/Controls
- **responsive.css** – Responsive Styles für verschiedene Bildschirmgrößen
- **assets/** – Bilder, Audio, Fonts und Videos
- **modules/** – JavaScript-Klassen für Spiellogik (Character, World, Enemies, usw.)
- **scripts/** – Haupt-JavaScript-Dateien (z.B. game.js)

## Starten des Spiels

1. Öffne die `index.html` im Browser.
2. Das Spiel kann direkt gespielt werden, es ist keine Installation notwendig.

## Hinweise

- Für die beste Spielerfahrung wird ein moderner Browser empfohlen.
- Die Steuerung ist sowohl für Tastatur als auch für mobile Geräte optimiert.
- Die Styles sind modular aufgebaut und können bei Bedarf weiter angepasst werden.
